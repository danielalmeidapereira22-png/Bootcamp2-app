# Painel do Clima

## Autor
Seu Nome Completo - Matrícula 00000000

## Descrição
Aplicação web interativa que consulta a previsão do tempo de qualquer cidade em tempo real usando a API do Open-Meteo.

## API utilizada
- **Open-Meteo API**: https://open-meteo.com/
- **Endpoints consumidos**: 
  - Geocoding: `https://geocoding-api.open-meteo.com/v1/search`
  - Weather: `https://api.open-meteo.com/v1/forecast`

## Funcionalidades
- Busca de clima por nome de cidade
- Exibição de temperatura atual, velocidade e direção do vento
- Tratamento de erros para cidades não encontradas
